# Phase 0 — Speech Clip List

**Every speech clip to record for the speech-to-text tests (L1), already split between the speakers. Each speaker records only their own section.**

Status: v1 · 19 Oct 2026 · Part of Phase 0 · How to record: `02_recording_guide.md`

---

## How to use this list

- Find your speaker code (S01 to S07) and record every line in your section, in order. File names use the ID column (`stt_S03_HG14.wav`).
- **Read lines** (English, Hindi, Hinglish, names): say them naturally. You may change a word to sound like yourself (for example "gaya" to "gayi"); the founder then corrects the transcript.
- **Noise lines (NZ):** say the same sentence again with the named noise switched on.
- **Free speech (FS):** answer the question out loud for 10 to 20 seconds, in any language. Don't plan it. The founder writes down what was actually said.
- Numbers are written in words because they must be **said exactly as written**.
- **Split:** "hidden" clips (about 30%) are recorded the same way but kept aside for phase gates and release only (`02` section 9).
- All names, addresses and numbers in these lines are made up. Never replace them with real personal details.
